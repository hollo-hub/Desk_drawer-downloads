# Desk Drawer Study 2.0.0

Desk Drawer Study is a new local-first study workspace, distributed as a
separate Windows app alongside the main Desk Drawer desktop companion.

## What's new

- **Empty-by-default Desk:** new users start with an empty study desk and add
  their own courses and materials.
- **Interactive first-run tour:** the guide highlights actual controls and
  leaves them usable during the walkthrough.
- **Desk Buddy ghost:** added a crisp pixel-art buddy with idle, blink, focus,
  done, nudge, and paused states; animated hem and idle motion; ten shuffled,
  non-repeating encouragements; and a bouncing speech bubble.
- **Focus timer:** the Stopwatch starts at `00:00`; optional countdowns include
  25 minutes, 50 minutes, or a custom 1–180 whole minutes. A course-colored
  halo fades with elapsed stopwatch time or countdown progress and freezes
  while paused.
- **Study notes:** searchable, titled Markdown notes per course, with formatting
  helpers and local autosave.
- **Tasks and resources:** lightweight course tasks and grouped folders, links,
  and file references, including video files opened with the system's
  registered application.
- **History and stats:** session history, optional reflections, weekly study
  totals, and streak summaries.
- **Personalization:** light/dark themes, optional notifications and interface
  sounds, configurable Desk components, and optional Downloads filing.
- **Quieter interface:** removed recurring successful-save notices while
  keeping save errors visible; editable text remains selectable while
  non-editable interface text cannot be accidentally dragged.
- **Buddy presentation:** removed the decorative cube platform so the buddy
  stands on its own.
- **Separate app identity:** installs as Desk Drawer Study and stores study
  data independently of the main Desk Drawer app.

## Install

Download `Desk Drawer Study_2.0.0_x64-setup.exe` from this release and run it
on Windows. The app stores courses, notes, and tasks locally. No account or
cloud service is required.

## Important

Desk Drawer Study is an early release. Back up important study material and
review the private source repository's license and documentation before
redistributing the installer.
